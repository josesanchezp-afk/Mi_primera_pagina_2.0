📚 Descripción del proyecto

Este proyecto reúne y presenta mi aprendizaje durante el curso de Pensamiento Algorítmico y Programación.
Aquí encontrarás diferentes ejercicios, ejemplos y pequeños proyectos que he desarrollado para practicar los conceptos vistos en clase, como:

Uso de variables

Creación y llamada de funciones

Estructuras de control como condicionales y bucles

Organización del código en clases

Resolución de problemas mediante algoritmos paso a paso

El objetivo de esta página es mostrar mi proceso de aprendizaje, documentar cada tema con ejemplos claros y compartir el desarrollo de mis habilidades en programación. A medida que avance en el curso, iré agregando nuevas secciones, explicaciones y mejoras.
